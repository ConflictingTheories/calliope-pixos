📝 Easy Updates

Adding a New Game (Super Simple!)

  1. Add screenshot: website/assets/games/my-game.png (640x360px)
  2. Edit website/data/games.json:
{
  "id": "my-game",
  "title": "My Awesome Game",
  "description": "Description...",
  "image": "assets/games/my-game.png",
  "links": [
    {
      "label": "Play Now",
      "url": "path/to/game.html",
      "icon": "▶️",
      "external": false
    }
  ]
}

Refresh browser - done! ✨

Changing Colors

Edit CSS variables in website/css/styles.css (lines 10-15):

:root {
    --color-primary: #ff6b9d;    /* Main pink */
    --color-secondary: #4ecdc4;  /* Teal */
    --color-accent: #ffd93d;     /* Yellow */
    --color-bg: #0f0f1e;         /* Background */
}

🐛 Troubleshooting

Images Not Loading?

  • Check paths in games.json are relative: assets/games/image.png
  • Verify files exist in correct folders
  • Clear browser cache

Styles Not Applying?

  • Hard refresh: Cmd+Shift+R (Mac) or Ctrl+Shift+R (Windows)
  • Check browser console (F12) for errors
  • Verify css/styles.css path is correct in HTML

Games Not Showing?

  • Open browser console (F12) to check for errors
  • Verify games.json has valid JSON syntax
  • Check network tab to see if JSON loads
