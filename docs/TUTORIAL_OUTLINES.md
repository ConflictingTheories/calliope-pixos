# PixoSpritz Video Tutorial Outlines

## Series 1: Getting Started (5 videos, ~5 min each)

### 1.1: Your First Map (5:00)
- Open editor, create project
- Map editor tour: toolbar, palette, layers
- Paint grass, path, walls
- Set spawn point
- Test with Ctrl+T
- **Outcome:** Playable empty map

### 1.2: Adding Characters (5:00)
- Add player sprite
- Add NPC sprite
- Behavior Editor: dialog + wander
- Test interaction (E key)
- **Outcome:** Talking NPC

### 1.3: Linking Maps with Portals (6:00)
- Create second map
- Portal Editor: add portals to both maps
- Link them together
- Test walking through
- **Outcome:** Two connected maps

### 1.4: Your First Script (7:00)
- Mode Editor: open update.pxs
- PixoScript basics: variables, if, functions
- Make NPC give item on first talk
- Use flags to track state
- **Outcome:** Quest-like interaction

### 1.5: Publishing to SVRN (4:00)
- Publish preview
- Checklist walkthrough
- Publish button
- View live zine
- Share link
- **Outcome:** Published game

## Series 2: Going Deeper (5 videos, ~8 min each)

### 2.1: Combat System (8:00)
- Battle mode setup
- Turn order, HP, attack
- Enemy AI basics
- Win/lose conditions

### 2.2: Custom Shaders (8:00)
- Shader Editor tour
- Modify fragment shader
- Add time-based animation
- Save as preset

### 2.3: Lighting (7:00)
- Light Editor: add point lights
- Color and intensity
- Day/night cycle via script

### 2.4: Cutscenes (8:00)
- Cutscene tool tour
- Timeline, dialogue, camera
- Trigger from portal
- Effects and transitions

### 2.5: GLTF Models (7:00)
- Import .glb file
- Place in scene
- Materials and lighting
- Animation playback

## Production Notes
- Record at 1080p, 60fps
- Zoom to 150% for code readability
- Captions required
- Each video ends with "next video" card
