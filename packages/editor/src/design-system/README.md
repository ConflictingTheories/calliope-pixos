# PixoSpritz Editor — Canonical Design Tokens (P2-08)

## Brand direction (Kyle, 2026-10-06)

**Primary is ACHROMATIC** — not teal, not pink. `--color-brand-primary`
is a high-contrast neutral (`#ececf1`, near-white) with dark text
(`--color-on-brand-primary`). Chromatic accents (teal secondary, pink
accent, amber warm) are secondary and minimal. This reconciles the old
pink-vs-teal-vs-indigo conflict: there is exactly one primary now.

**Canonical token tree:** `src/design-system/`

- `design-system.css` — CSS custom properties (`--color-*`, `--space-*`,
  `--radius-*`, …). This is the single source of truth for token *names*.
- `index.js` — the same tokens as a JS module for non-CSS use.

## What this decision covers

P2-08 unified the editor shell on one component/token tree:

- New shell code (command palette, save-status indicator, tool panels)
  uses `--color-*` tokens from this directory.
- `src/ui/` remains the component library (Panel, Button, inputs…);
  its `theme.css` is a legacy mapping layer, not a second token source.
- `src/styles/design-system.css` ("Professional UI Polish") keeps its
  component styles; its `:root` token block is superseded by this
  directory for all new code.

## P0-03 seam (other track)

Token *values* may be regenerated by the foundation track (P0-03),
which owns visual snapshots. Until then, **no visual changes**:
existing stylesheets keep their current computed values. P0-03
should reconcile the `--bg-*`/`--brand-*` legacy names in
`src/styles/design-system.css` and the `--panel-bg`-style names in
`src/ui/theme.css` onto the `--color-*` names here, with snapshot
coverage.
