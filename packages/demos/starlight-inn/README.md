# Starlight Inn

A cozy visual-novel-style sample game. Run an inn, talk to travelers, make choices.

## What it showcases

- **Dialog behaviors:** NPCs with declarative dialogue
- **Script hooks:** Custom `onInteract` logic in PixoScript
- **Movement:** Simple WASD exploration
- **Atmosphere:** Single-room setting with fireplace

## How to play

- **WASD/Arrows:** Walk around the inn
- **E/Space:** Talk to the innkeeper

## Files

```
manifest.json
maps/inn/map.json + cells.json
modes/story/mode.json + setup.pxs + update.pxs
```
